# Isme Grout Bhar Denge

Koi bhi problem ho. Isme grout bhar denge.

A mobile-friendly meme landing page for ismegroutbhardenge.com, with embedded meme image and audio, rotating jokes, sharing and domain offers via @itsmosin on X.

## Deploy on Vercel

1. Create a GitHub repository and upload `index.html`, `vercel.json` and `README.md` to its root.
2. Visit https://vercel.com/new and import the repository.
3. Select Other as the framework preset and leave the root directory at `./`. No build or installation is required; the configuration serves the repository root.
4. Click Deploy and test the generated URL.
5. In Project Settings > Domains, add `ismegroutbhardenge.com` and optionally `www.ismegroutbhardenge.com` as a redirect.
6. If using Vercel DNS, verify that GoDaddy uses `ns1.vercel-dns.com` and `ns2.vercel-dns.com`. Wait for valid configuration and HTTPS.

## Local preview

Open `index.html` in a browser, or run `python3 -m http.server 8000` from the repository root and visit http://localhost:8000.

## Updating the site

Edit `index.html` and commit the changes to the connected production branch. Vercel will redeploy automatically if Git integration is enabled.

The displayed $2,000 bid is static, not a live auction. Only label it a current bid if it reflects a genuine offer; otherwise use asking price. Offers are handled externally through X. No backend or payment processing is included.

Check Vercel's plan terms for commercial use before deployment.
